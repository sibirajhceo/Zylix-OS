# Zylix OS — Product

**Canonical source: [prodSpec.md](../prodSpec.md)**

## First User

Sibirajh — a founder who runs a creative studio (Zylix Edit House), manages client projects, handles college responsibilities, and builds personal products.

## Problem

Sibirajh's operational data is scattered across multiple tools, chat threads, memory, and notebooks. There is no single place to dump a brain fragment and get structured answers about tasks, projects, payments, waiting items, and decisions. Existing tools are either too rigid (project management software) or too generic (notes apps).

## Product Promise

A private, AI-first personal operating system that:

- Accepts natural-language brain dumps
- Answers operational questions immediately
- Maintains structured data about tasks, projects, clients, payments, and decisions
- Works across every device Sibirajh uses

## Primary Workflows

1. **Brain dump** — type or speak a raw thought; the AI structures it into tasks, updates projects, or records decisions
2. **Morning review** — "What should I focus on today?" returns prioritised tasks
3. **Project tracking** — review all active projects with next actions
4. **Payment follow-up** — see pending payments, who owes what, and when to follow up
5. **Waiting list** — everything Sibirajh is blocked on, grouped by person or client
6. **Decision log** — record and retrieve past decisions with context

## MVP Boundaries

Milestone 0 delivers only the frontend shell with realistic mock data. No AI, no database, no authentication.

## Non-Goals

- Generic project management for teams
- Public social features
- Billing or subscription management
- Third-party integrations beyond AI and Supabase
- Native mobile apps in MVP phase (responsive web only)

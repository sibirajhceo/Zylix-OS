# Zylix OS Agent Guidelines

## Taste Skill (design-taste-frontend)

Taste Skill is mandatory for every frontend design, implementation, redesign, responsive-layout, component-polish, and visual-QA task.

Before changing frontend code, read the installed design-taste-frontend skill and declare a one-line Design Read.

Apply the skill contextually. Zylix OS is an AI-first product workspace, not a marketing landing page. Do not introduce landing-page hero patterns, excessive motion, decorative section layouts, or marketing-card clichés into operational product screens.

Product usability, accessibility, information hierarchy, responsive behaviour, and performance override decorative rules when they conflict.

# Zylix OS — Product Specification

**Canonical product document.** Other product summaries reference this file.

## Product Name

Zylix OS

## Owner and First User

Sibirajh

## Problem

Sibirajh's operational data is scattered across tools, chat threads, memory and notebooks. No single place accepts a natural-language brain dump and returns structured answers about tasks, projects, payments, waiting items and decisions.

## Product Promise

A private, AI-first personal operating system that:

- Accepts natural-language brain dumps
- Answers operational questions immediately
- Maintains structured data about tasks, projects, clients, payments and decisions
- Works across every device Sibirajh uses

## Target Platforms

- Mac (primary)
- Android
- iPhone
- Modern desktop and mobile browsers

## Primary Workflows

1. **Brain dump** — type or speak a raw thought; AI structures it into tasks, updates projects or records decisions
2. **Morning review** — "What should I focus on today?" returns prioritised tasks
3. **Project tracking** — review active projects with next actions
4. **Payment follow-up** — see pending payments, who owes what, follow-up timing
5. **Waiting list** — everything blocked on, grouped by person or dependency
6. **Decision log** — record and retrieve past decisions with context

## MVP Boundaries (Milestones 0–2)

- Frontend shell with realistic mock data only
- No real AI until Milestone 4
- No real data persistence until Milestone 2
- Responsive web only (no native wrappers in MVP)

## Non-Goals

- Generic project management for teams
- Public social features
- Billing or subscription management
- Third-party integrations beyond AI and Supabase
- Native mobile apps in MVP phase
